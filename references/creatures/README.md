# Etsa EverExpanding — Approved Creature Designs

This folder contains the APPROVED creature designs for Etsa EverExpanding.

Each image has been designed and reviewed before being placed here.

IMPORTANT FOR CODEX:

- Treat the uploaded images as the primary visual reference for each creature.
- Recreate the creature as closely as reasonably possible in 3D.
- Match its body shape, proportions, anatomy, colors, horns, wings, legs, tail, tentacles, eyes, and other visible features.
- Preserve the creature's recognizable silhouette.
- Add appropriate 3D depth and details where the reference image does not show them.
- Do not redesign or replace an approved creature unless specifically instructed.
- Creature movement and animation must match its anatomy.

Examples:

Wyvern:
Flying creature with appropriate wing, body, leg, head, and tail animation.

Giant Squid:
Large aquatic creature with swimming body motion and independently animated tentacles.

Only images intentionally uploaded to this folder should be treated as approved creature designs.
